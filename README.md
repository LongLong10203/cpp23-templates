# C++23 Templates

A growing collection of header-only C++23 templates for competitive programming by Long.

Include the `.hpp` files you need and compile with C++23 enabled. Each header includes its standard-library dependencies and has an include guard.

See the [documentation](docs.md) for setup, examples, and usage notes. The templates are verified with Apple Clang 21 on Apple Silicon.

This project is a work in progress. Bug reports, improvements, and pull requests are welcome.

Most templates were generated with Claude Opus 5.5, prompted and refined by Long.
